# Fused Embedding Pipeline

Integrate GEOM molecular descriptors, LINCS expression signatures, JUMP
cell-morphology features, and NCI60 drug-response profiles into compound
embeddings, with ATC and mechanism-of-action prediction QC.

- [User guide](https://github.com/bhklab/fused-embedding-pipeline#readme): run an
  existing applet through the DNAnexus portal or CLI and review its outputs.
- [Deployment guide](dnanexus.md): build the container and applet and share them
  with collaborators.
- [Data sources](data_sources.md): input datasets and configuration.
- [Maintenance](devnotes.md): source files and deployment updates.
